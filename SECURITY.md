# Security policy

Please **do not** open public issues for vulnerabilities. Report them privately:

1. **Preferred:** GitHub private vulnerability reporting — [Report a vulnerability](https://github.com/Om1938/releaser/security/advisories/new) (Security tab → Advisories).
2. **Alternative:** email [omkletu+releaser@gmail.com](mailto:omkletu+releaser@gmail.com).

Include steps to reproduce, the affected version or commit, and the impact you observed.

We aim to acknowledge reports within 3 working days and ship fixes for confirmed issues in a patch release. The security model is described in [docs/security.md](docs/security.md).
